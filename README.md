# Amazon Product Review Sentiment Analysis

## 📌 Project Overview

This project performs **sentiment analysis on Amazon product reviews** using Natural Language Processing (NLP) and Machine Learning.

The main objective is to classify customer reviews into two sentiment categories:

- 🟢 Positive
- 🔴 Negative

The project covers the complete machine learning workflow, from data cleaning and text preprocessing to feature extraction, model training, evaluation, and prediction on new reviews.

---

## 📊 Dataset

The project uses the **Amazon Fine Food Reviews** dataset obtained from Kaggle.

The original dataset contains approximately **568,454 customer reviews** and 10 columns.

### Dataset Columns

| Column                   | Description                                     |
| ------------------------ | ----------------------------------------------- |
| `Id`                     | Unique review ID                                |
| `ProductId`              | Unique product identifier                       |
| `UserId`                 | Unique customer identifier                      |
| `ProfileName`            | Customer profile name                           |
| `HelpfulnessNumerator`   | Number of users who found the review helpful    |
| `HelpfulnessDenominator` | Total number of users who evaluated helpfulness |
| `Score`                  | Product rating from 1 to 5                      |
| `Time`                   | Review timestamp                                |
| `Summary`                | Short review summary                            |
| `Text`                   | Full customer review                            |

For sentiment analysis, the primary columns used were:

- `Text` — customer review
- `Score` — product rating

### Sentiment Labeling

The original ratings were converted into binary sentiment classes:

| Rating | Sentiment |
| ------ | --------- |
| 1–2    | Negative  |
| 3      | Removed   |
| 4–5    | Positive  |

Three-star reviews were removed because this project focuses on **binary sentiment classification**.

## 🧹 Data Preprocessing

The review data was cleaned and prepared using the following steps:

1. Inspected dataset structure and columns
2. Checked and handled missing values
3. Removed duplicate records
4. Removed neutral 3-star reviews
5. Created binary sentiment labels
6. Converted text to lowercase
7. Removed HTML tags
8. Removed special characters and numbers
9. Removed extra spaces
10. Tokenized the review text using NLTK
11. Removed English stopwords
12. Preserved important negation words such as `not`, `no`, and `never`

---

## 🔢 Feature Extraction — TF-IDF

Machine learning models cannot directly process raw text, so **TF-IDF (Term Frequency-Inverse Document Frequency)** was used to convert customer reviews into numerical features.

The TF-IDF vectorizer was configured with:

```text
Maximum features: 20,000
N-gram range: (1, 2)
Minimum document frequency: 2
Maximum document frequency: 95%
```

Using `ngram_range=(1, 2)` allows the model to learn both:

- **Unigrams:** `excellent`, `product`, `quality`
- **Bigrams:** `excellent product`, `good quality`

## 🤖 Machine Learning Models

Two binary classification models were implemented.

### 1. Logistic Regression

Logistic Regression was used as the primary classification model to predict whether a review was positive or negative.

### 2. Multinomial Naive Bayes

Multinomial Naive Bayes was implemented as a second model to compare its performance with Logistic Regression.
